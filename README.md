# 로또
## 진행 방법
* 로또 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

### LottoNumber

- [x] 1~45 밖의 숫자는 예외 (0, 46 → 실패)

- [x] 숫자 그대로 출력된다. (7 → "7")

### Lottos
#### 고민요소 : LottoNumberGenerator 를 주입 받는 식으로 미리 바꿔둬야 할지: 현재 요구사항으론 큰 이점이 없어보임
- [x] 구입 금액만큼 로또가 만들어진다. (14000 → 14장, 1000 → 1장)
- [x] 구입 금액이 1000원 미만이면 예외 (500 → 실패, 0 → 실패) (직접 정한 부분)
- [x] 구입 금액이 1000원 단위가 아니면 예외 (14500 → 실패) (직접 정한 부분)
- [x] 생성기가 아닌 로또 목록으로도 만들 수 있다. ([1~6], [7~12] → 2장)
- [x] 6개 숫자가 모두 같은 로또도 중복으로 가질 수 있다. ([1~6], [1~6] → 2장) (직접 정한 부분)
- [x] 구입 금액은 List.size x 1000 원이다. (14장 → 14000원)
- [x] 로또 목록이 비어 있으면 예외 ([] → 실패) (직접 정한 부분)
- [x] 당첨 로또와 맞춰 본 결과를 만든다. ([1,2,3,7,8,9] vs [1~6] → 3개 일치 1장, 수익률 5.0)

### LottoResult
#### 고민요소 : 어떤 로또가 몇 등인지까지 알아야 할까.. (일단 현 요구사항에 맞게 진행)
- [x] 일치 개수별 로또 장수를 알 수 있다. (3개 일치 1장 → 1, 4개 일치 없음 → 0)
- [x] 총 상금을 알 수 있다. (3개 일치 1장 → 5000원)
- [x] 총 상금은 long으로 계산한다. (6개 일치 2장 → 4000000000원) (직접 정한 부분)
- [x] 수익률은 "총 상금 / (구입 장수 × 1000)" (5000 / 14000 → 0.35, 버림)
- [x] 당첨이 없을 때 수익률 (0원 → 0.0)
- [x] 등수 목록이 비어 있으면 예외 ([] → 실패) (직접 정한 부분)
