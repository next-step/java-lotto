# 문자열 계산기

## 기능 요구사항

- 사용자가 입력한 문자열 값에 따라 사칙연산을 수행하는 계산기를 구현한다.
- 입력 문자열의 숫자와 사칙 연산 사이에는 반드시 빈 공백 문자열이 있다.
- 나눗셈의 경우 결과 값을 정수로 떨어지는 값으로 한정한다.
- 문자열 계산기는 사칙연산의 계산 우선수위가 아닌 입력 값에 따라 계산한다.

## 기능 목록

계산기

- 문자열을 공백 단위로 분리한다.
- 계산 가능한 형태인지 확인한다.
- 덧셈
- 뺄셈
- 곱셈
- 나눗셈(정수만 허용)

입력

- 문자열을 입력받는다.
  - 입력값이 null 이거나 빈 공백인 경우 예외 발생

출력

- 연산 결과를 출력한다.
