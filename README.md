# 로또
## 진행 방법
* 로또 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 온라인 코드 리뷰 과정
* [텍스트와 이미지로 살펴보는 온라인 코드 리뷰 과정](https://github.com/next-step/nextstep-docs/tree/master/codereview)

# 문자열 계산기 미션
## 문자열 계산기
- 수식을 계산한다.
## 숫자
- 사칙연산을 수행할 수 있다.
## 연산자 팩토리
- 연산 기호에 맞는 객체를 생성한다.
- 사칙 연산이 아닌 기호를 판별한다.
## 덧셈
- 더하기를 수행한다.
## 뺄셈
- 빼기를 수행한다.
## 곱셈
- 곱하기를 수행한다.
## 나눗셈
- 나누기를 수행한다.
## 파서
- 수식을 파싱한다.


# 로또
## 가격
- 살 수 있는 로또의 개수를 계산한다.
## 로또 숫자
- 로또의 숫자간의 비교가 가능하다.
## 로또 숫자들
- 로또 숫자들간의 비교가 가능하다
## 로또
- 가격에 따른 로또를 뽑는다.
## 나의 로또
- 내가 뽑은 로또 숫자들의 집합
## 당첨 번호
- 지난 회차의 당첨 번호를 가지고 있다.
- 3, 4, 5, 6개의 당첨에 따른 가격을 알 수 있다.
- 3, 4, 5, 6개의 당첨 횟수를 알 수 있다.
- 당첨 수익률을 알 수 있다.
