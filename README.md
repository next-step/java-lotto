# 로또
## 진행 방법
* 로또 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 온라인 코드 리뷰 과정
* [텍스트와 이미지로 살펴보는 온라인 코드 리뷰 과정](https://github.com/next-step/nextstep-docs/tree/master/codereview)


### 요구사항
- [ ] 로또 번호는 1~45 사이만 허용한다 (46 -> 예외)
- [ ] 중복되지 않는 번호를 6개를 생성한다
- [ ] 당첨번호 문자열을 번호로 바꾼다 ("1, 2, 3, 4, 5, 6" -> 1, 2, 3, 4, 5, 6)
- [ ] 14,000원을 입력하면 로또 14장을 구입한다
- [ ] 당첨번호와 셔플된 번호가 몇개 일치하는지 확인한다 
- [ ] 3개 일치하면 5,000원을 지급한다
- [ ] 4개 일치하면 50,000원을 지급한다
- [ ] 5개 일치하면 1,500,000원을 지급한다
- [ ] 6개 일치하면 2,000,000,000원을 지급한다
- [ ] 총 당첨금을 구입 금액으로 나눠 수익률을 계산한다 (5000원 당첨, 14000원 구입 -> 0.35)
