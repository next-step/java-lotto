# 기능 요구사항

> 입력한 금액만큼 로또 자동으로 발급해주는 기능

1. 구입 금액 입력 기능
2. N개의 로또 구매 기능 (자동)
3. 당첨 번호 입력 기능
4. 당첨 통계 조회 기능
    - 몇 개의 번호가 일치하는지, 몇 개인지
    - 수익률

# 주요 객체

## 로또 머신 (LottoMachine)

- 무엇인가? : 구매금에 따라 로또를 생성해주는 머신
- 역할
    - 로또 발급 개수

## 로또 (LottoTicket)

- 무엇인가? : 6개의 고유한 숫자를 담은 로또 티켓
- 역할
    - 6개의 숫자 보관
    - 일치 갯수 비교

## 로또 숫자 (LottoNumber)

- 무엇인가? : 로또 내 숫자
- 역할
    - 번호 유효성 보장 (1 ~ 45)
    - 숫자 객체 비교

## 당첨된 로또 (WinningLotto)

- 무엇인가? : 당첨 결과 정보 (6개의 숫자)
- 역할
    - 당첨 번호 비교

## 당첨 등수 (Rank)

- 무엇인가? : 당첨 결과 유형 (몇 개의 번호 일치, 당첨금)

## 로또 결과 (LottoResult)

- 무엇인가? : 어떤 Rank에 해당되는지 정보

## 로또 게임 결과 (Result)

- 무엇인가? : 전체 로또 구매 결과 (당첨 통계, 수익률)을 나타내는 객체
- 역할
    - 당첨 통계와 수익률을 포함하는 객체

### 당첨 통계 Statistics

- 일치하는 번호 갯수, 몇 개

### 수익률 ProfitRate

- 수익률 = 당첨 금액 / 구입 금액 * 100
