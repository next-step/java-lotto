# 요구사항

- 문자열 값에 따라 사칙연산(덧셈, 뺄셈, 곱셈, 나눗셈)을 수행한다
    - 입력 문자열의 숫자와 사칙 연산 사이에는 빈 공백 문자열이 있다
        - 입력 값이 null이거나 빈 공백 문자일 경우 IllegalArgumentException throw
        - 사칙연산 기호가 아닌 경우 IllegalArgumentException throw
    - 나눗셈은 정수로 떨어진다
    - 입력 순서에 따라 계산 순서가 결정된다

# 기능 목록

## 1. 입력 검증

- [X] null이거나 빈 공백 문자일 경우 IllegalArgumentException 발생
- [X] 올바르지 않은 연산자 (+-*/외) 입력 시 IllegalArgumentException 발생
- [x] 올바르지 않은 형식 입력시 예외 발생

## 2. 문자열 파싱

- [X] 공백을 기준으로 문자열 분리
- [x] 숫자와 연산자를 구분하여 저장

## 3. 사칙연산 계산

- [x] 덧셈
- [x] 나눗셈
- [x] 곱셈
- [x] 뺄셈

## 4. 순차 계산

- [x] 입력 순서대로 왼쪽부터 오른쪽으로 계산

# 흐름

```markdown
1. 무엇을 해야 하는지 책임 분리하기

- 입력 검증
- 문자열을 숫자와 연산자로 분리
- 연산 수행
- 연산 결과 계산

2. 명사와 동사 찾기

- 명사(객체후보) : 계산기, 입력값, 연산자, 수식, 숫자
- 동사(메서드후보) : 검증하다, 파싱하다, 계산하다, 연산하다

3. 객체 후보 설계

- Calculator(계산기) : 전체 흐름 제어
- Expression(수식)
- Operator(연산자)
- Number(숫자)
- Tokenizer(분리자)
```
