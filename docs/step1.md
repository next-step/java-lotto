# 🚀 1단계 - 로또(자동)

## 구현할 기능 목록 (도메인)

- [ ] 로또 한 장은 1부터 45 사이의 중복되지 않는 번호 6개를 가진다
- [ ] 로또 번호는 오름차순으로 정렬한다
- [ ] 구입 금액으로 살 수 있는 로또 수를 구한다
- [ ] 구입한 수만큼 로또를 발급한다
- [ ] 로또와 당첨 번호가 몇 개 일치하는지 센다
- [ ] 일치 개수로 당첨 등수를 정한다
- [ ] 등수별 당첨 횟수를 센다
- [ ] 당첨 금액의 합을 구입 금액으로 나눠 수익률을 구한다

## 입출력 (UI)

- [ ] 구입 금액을 입력받는다
- [ ] 지난 주 당첨 번호를 쉼표로 구분해 입력받는다
- [ ] 구매한 로또를 출력한다
- [ ] 당첨 통계와 수익률을 출력한다
