# Lotto todos (step1)
## 로또
- [x] 숫자가 6개가 아니면 예외가 발생한다.
- [x] 1 ~ 45 범위를 벗어난 숫자가 있으면 예외가 발생한다.
- [x] 중복된 숫자가 있으면 예외가 발생한다.
- [x] 숫자들을 오름차순으로 정렬해서 가진다.
- [x] 가지고 있는 숫자들을 반환한다.
- [x] 다른 로또와 일치하는 숫자의 개수를 반환한다.

## 당첨 번호
- [x] 로또(당첨 번호 6개)를 가진다.
- [x] 로또를 입력받아 등수를 반환한다.

## 등수
- [x] 등수별 일치 개수와 상금을 가진다. (3개 5000원, 4개 50000원, 5개 1500000원, 6개 2000000000원)
- [x] 일치 개수에 맞는 등수를 반환한다.
- [x] 3개 미만 일치는 낙첨으로 처리한다.

## 로또 번호 생성
- [ ] 1 ~ 45 사이의 중복 없는 숫자 6개를 생성한다.

## 구입 금액
- [ ] 로또 1장의 가격은 1000원이다.
- [ ] 1000원 미만이면 예외가 발생한다.
- [ ] 1000원 단위가 아닐 땐 나머지 버린다.
- [ ] 구매 가능한 로또 개수를 반환한다.

## 로또 게임
- [ ] 생성 방법을 전달받아 구입 금액만큼 로또를 생성한다.
- [ ] 진행중인 로또를 반환한다.
- [ ] 당첨 번호를 입력받아 로또 결과를 반환한다.

## 로또 결과
- [ ] 등수 목록과 구입 금액을 가지고 생성된다.
- [ ] 등수별 당첨 개수를 집계한다.
- [ ] 당첨되지 않은 등수는 0개로 반환한다.
- [ ] 총 당첨 금액을 계산한다.
- [ ] 수익률(총 당첨 금액 / 구입 금액)을 계산한다.
- [ ] 수익률은 소수점 둘째 자리까지 버림 처리한다.

## 입력
- [ ] 구입 금액을 입력받는다.
- [ ] 구입 금액이 숫자가 아니면 예외가 발생한다.
- [ ] 지난 주 당첨 번호를 입력받는다.
- [ ] 쉼표로 구분된 문자열을 공백을 제거해 숫자 리스트로 변환한다.
- [ ] 당첨 번호에 숫자가 아닌 값이 있으면 예외가 발생한다.

## 출력
- [ ] 구매한 로또 개수를 출력한다. (`N개를 구매했습니다.`)
- [ ] 로또를 전달받아 목록을 출력한다. (`[1, 2, 3, 4, 5, 6]`)
- [ ] 당첨 통계를 3개 일치부터 6개 일치까지 순서대로 출력한다. (`3개 일치 (5000원)- 1개`)
- [ ] 당첨 통계에 낙첨은 출력하지 않는다.
- [ ] 수익률을 출력한다. (`총 수익률은 0.35입니다.`)
- [ ] 수익률이 1 미만이면 손해라는 안내 문구를 함께 출력한다.
