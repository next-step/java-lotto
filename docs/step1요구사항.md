# 문자열 사칙 연산 계산기 구현
## 기능 요구사항

### 계산기
- [ ] 입력받은 문자열을 파싱하여 숫자와 연산자를 추출한다
- [ ] 연산 우선순위를 무시하고 입력 순서대로 계산한다
  - [ ] 이전 연산 결과를 다음 연산결과의 피연산자로 사용한다. ex): "2 + 3 * 4" → (2 + 3) * 4)
- [ ] 왼쪽부터 오른쪽으로 순차적으로 계산을 진행한다
- [ ] 최종 계산 결과를 반환한다

### 연산자
- [x] 덧셈 연산을 수행한다
- [x] 뺄셈 연산을 수행한다
- [x] 곱셈 연산을 수행한다
- [x] 나눗셈 연산을 수행한다
    - [x] 나눗셈의 결과는 정수로 떨어진다고 가정한다
- [x] 사칙연산 기호가 아닌 경우 IllegalArgumentException을 발생시킨다
- 
### 입력
- [ ] 사용자로부터 사칙연산 문자열을 입력받는다
- [ ] 입력 문자열의 숫자와 연산자 사이에는 공백이 있다고 가정한다
- [ ] null 또는 빈 문자열이 입력되면 IllegalArgumentException을 발생시킨다
- [ ] 입력 문자열을 공백 기준으로 분리한다

### 출력
- [ ] 계산 결과를 정수로 출력한다
- [ ] 예외 발생 시 에러 메시지를 출력한다
