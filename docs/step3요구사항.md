# 로또 구현

## 기능 요구사항

## 입력

- [ ] 보너스 번호를 입력받는다

## 보너스 번호

- [ ] 보너스 번호는 1부터 45 사이의 숫자이다
- [ ] 보너스 번호 범위를 벗어나면 IllegalArgumentException을 발생시킨다
- [ ] 보너스 번호는 당첨 번호와 겹치지 않는다
    - [ ] 보너스 번호가 당첨 번호와 겹치면 IllegalArgumentException을 발생시킨다

## 당첨 번호 (보류)

- [ ] 당첨 번호 6개와 보너스 번호 1개를 가진다
- [ ] 당첨 번호와 보너스 번호는 겹치지 않는다

## 로또

- [ ] 당첨 번호와 비교하여 등수를 반환한다.
- [ ] 보너스 번호가 있는지 확인한다.

## 구입 금액

- [x] 구입 금액을 입력받는다
- [x] 1000원 단위가 아니면 IllegalArgumentException을 발생시킨다
- [x] 0원 이하면 IllegalArgumentException을 발생시킨다

## 로또번호 생성기

- [x] 1부터 45까지의 숫자를 생성한다
- [x] 생성한 숫자를 섞고나서 6개를 선택하여 반환한다

## 로또 티켓

- [x] 구입 금액을 1000으로 나눈 갯수큼 로또 티켓을 발행한다.

## 당첨 번호

- [ ] 

## 랭킹

- [] 변경된 2등 랭킹을 추가한다.

## 당첨결과

- [ ] 각 등수별 당첨 개수를 집계한다 (2등 포함)
- [ ] 번호 일치 갯수와 보너스 일치 여부를 계산해서 등수를 매긴다

## 출력

- [ ] 당첨 통계를 출력한다(2등 포함)
